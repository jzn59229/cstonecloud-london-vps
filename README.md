## 双 ISP 住宅 IP 是怎么回事，跟普通 VPS IP 差在哪

这里我得先把概念掰扯清楚，因为很多人把"原生 IP""住宅 IP""双 ISP"混在一起说，其实它们侧重点不一样。

**原生 IP** 指的是这个 IP 地址的归属地确实在英国，不是通过中转或代理伪装出来的。**住宅 IP** 指的是 IP 的 ASN 属性属于家庭宽带运营商（比如 Sky、BT、Virgin Media 这类），而不是托管商或云服务商。**双 ISP** 则是这个 IP 同时被两家运营商认证，流量可以根据网络情况在两条 ISP 线路之间走，既增加冗余，也让连接模式看起来更像普通家庭用户的多线路环境。
